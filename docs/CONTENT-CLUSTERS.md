# Content clusters: where they sit

Source: docs/brief/Content Clusters.docx. Onyinye writes the content. This file says where each piece lives so it
links into the site structure and so the structured data and internal links work.

## How to publish

Each question below is an article in **Insights** (`/insights/<slug>`), written in Admin > Blog. Articles link up to
their hub page and across to related courses. Hub pages already list "Related articles" automatically when a post
title contains the hub's topic words, so use the topic words in the title.
